# Amit Karmon — personal website draft

This is a static academic website. It can be hosted free on GitHub Pages, Netlify, Cloudflare Pages, or another static host.

## Files

- `index.html` — homepage
- `cv.html` — CV page with an embedded PDF
- `styles.css` — visual design
- `assets/amit-karmon.jpg` — web portrait (metadata removed)
- `files/amit-karmon-cv.pdf` — downloadable CV in PDF format
- `files/amit-karmon-cv.docx` — editable CV source
- `files/learning-complexity-paradoxes-confirmation.pdf` — DPhil thesis

## Before publishing

1. Review and approve every piece of website copy.
2. Decide whether to add a Projects page; no project descriptions have been added yet.
3. After the viva, update the DPhil wording and dates on the homepage and in the CV.
4. Add a Google Scholar link when the profile is available.
5. Once the site has a final address, add it to the blank Website field in the CV and regenerate the PDF.

## Local preview

Open `index.html` in a browser, or run a local server in this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
